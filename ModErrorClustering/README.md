This is a collection of the scripts used to cluster the mod compilation errors
fixed by this plugin in addition to the general .NET 10 compatibility of the game.
All the mod compilation errors listed in the `clustered_errors.txt` files have
been fixed. Testing was conducted only on the servers listed in `ServersTested.txt`
and on the on the highest voted 599 (3*200-1) mods. The votes were collected from
the Steam Web API. One mod [3588218990] "My Crew" is broken, so it was removed.
The functionality of the mods have not been tested, only the mod compilation and
loading into a world.
